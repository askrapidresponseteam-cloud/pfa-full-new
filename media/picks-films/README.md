# Maneka's Picks film stills

Empty until `npm run media:films` is run with a network connection.
DEPLOY.command runs it, so a deploy fills this folder.

Each file is `<youtube-id>.jpg`, the still YouTube publishes for that film,
downloaded once rather than hot-linked. Until it is here, a tile keeps its
number and its play button, so the page is correct before this folder is
filled and better after.

The films (manekas-picks.html, `FILMS`):

- `jvTxVAMrgGA` Test Subject V, official trailer (JioHotstar)
- `Y4ftPP5XnAk` Oslo: A Tail of Promise, official teaser (Protecterra Ecological Foundation)
- `Hkv1-F5-EaI` Ohh My Dog, official trailer (Babulal Biscope)
